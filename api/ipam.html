IPAM 接口 ​

IPAM（IP Address Management）接口提供网段规划、IP 地址分配、设备绑定与在线探测能力，支持 IPv4 / IPv6 双栈与无限层级子网嵌套。

版本说明：IPAM 模块自 v2.8.3 起提供 IP 与设备关联能力；v2.8.4 起提供定时探测调度配置。

接口前缀 ​

/api/ipam

IPAM 路由整体位于全局认证中间件（app.use('/api', authMiddleware)）之后，所有请求必须携带有效 Token；但未在 init-permissions.js 中注册独立权限码，因此不额外校验模块级权限（当前所有已登录用户均可访问）。生产环境如需按角色隔离，建议在自定义角色中通过网关层或后续权限码扩展实现。

数据模型 ​

网段模型（Subnet） ​

字段类型说明
subnetIdstring (PK)主键，自动生成为 SUBNET{时间戳36进制}{6位随机}
namestring网段名称（必填）
ipVersionenum地址族：ipv4、ipv6
cidrstringCIDR 表示，如 192.168.1.0/24、2001:db8::/32（必填）
networkAddressstring网络地址（由 CIDR 自动解析）
broadcastAddressstring广播地址；IPv6 使用前缀末地址代替
netmaskstring子网掩码，IPv6 不使用
prefixLengthinteger前缀长度（IPv4 为 8~32，IPv6 为 0~128）
startInt / endIntdecimal(39,0)网段起止地址的 128 位整数表示，用于范围查询
totalHosts / usableHostsstring主机总数 / 可用主机数（字符串存储，避免 IPv6 精度丢失）
gatewaystring网关地址
dnsjsonDNS 服务器数组
vlanIdstringVLAN ID
parentIdstring父网段 ID，支持无限层级嵌套
purposeenum网段默认用途：management、business、public、storage、other；网段内新建 IP 时作为 ipType 推荐值
autoGeneratedboolean是否已自动生成 IP 记录（IPv6 恒为 false）
descriptionstring备注

唯一约束：networkAddress + prefixLength 组合唯一。

IP 地址模型（IpAddress） ​

字段类型说明
ipIdstring (PK)主键，自动生成为 IP{时间戳36进制}{6位随机}
subnetIdstring所属网段 ID
ipVersionenumipv4、ipv6
ipAddressstringIP 地址字符串
ipInt / ipInt128bigint / decimalIPv4 整数与通用 128 位整数，用于排序与范围查询
statusenumfree、used、reserved、gateway、excluded
ipTypeenummanagement（带外管理）、business（带内业务）、public（公网）、storage（存储网）、other（其他）
customTagstring自定义标签，如「VIP」「主备」「cluster」
isPrimaryForDeviceboolean是否为所属设备的主 IP（每设备全局最多一个）
statusAutoDrivenboolean当前 used 状态是否由上次绑定自动设置；为 true 时解绑可自动回退 free
assignmentTypestring分配方式，默认 static
deviceIdstring绑定的设备编号
networkCardIdstring绑定的网卡 ID
label / descriptionstring标签与备注
probeStatusenum在线探测状态：unknown、online、offline
probeMethodstring探测成功方式：ping、tcp、both
probeLatencyinteger探测延迟（毫秒）

IP 状态语义 ​

状态说明是否可绑定设备
free空闲是
used已使用是（重复绑定时按业务规则处理）
reserved预留是
gateway网关地址绑定中的 IP 禁止改为该状态
excluded排除地址绑定中的 IP 禁止改为该状态

网段管理 ​

解析 CIDR ​

http
POST /api/ipam/parse-cidr

用于在创建网段前预览 CIDR 解析结果（网络地址、广播地址、掩码、主机数等），不写库。

请求体 ​

字段类型必填说明
cidrstring是待解析的 CIDR，如 10.10.0.0/16

响应示例 ​

json
{
  "success": true,
  "data": {
    "ipVersion": "ipv4",
    "networkAddress": "10.10.0.0",
    "broadcastAddress": "10.10.255.255",
    "netmask": "255.255.0.0",
    "prefixLength": 16,
    "totalHosts": "65536",
    "usableHosts": "65534"
  }
}

网段冲突检测 ​

http
GET /api/ipam/conflicts

返回当前所有网段之间存在的重叠关系。新建网段时后端亦会执行同样的检测。

冲突规则 ​

场景结果
新网段完全包含于已有网段（A_in_B）允许，作为已有网段的子网段
CIDR 完全相同拒绝，返回 400
部分重叠拒绝，返回 400
新网段覆盖已有网段拒绝，返回 400
不同地址族（IPv4 与 IPv6）跳过检测

获取网段列表 ​

http
GET /api/ipam/subnets

返回网段树形结构及其 IP 使用统计。

创建网段 ​

http
POST /api/ipam/subnets

请求体 ​

字段类型必填说明
namestring是网段名称
cidrstring是CIDR 表示
gatewaystring否网关地址
dnsarray否DNS 服务器列表
vlanIdstring否VLAN ID
parentIdstring否父网段 ID，必须能容纳新网段范围
purposestring否网段默认用途
descriptionstring否备注

处理流程 ​

  1. 解析 CIDR 得到地址族与范围
  2. 事务外读取全部网段，完成冲突检测与父网段归属匹配（乐观锁，不长时间持有数据库锁）
  3. 计算可用主机数，按需自动生成 IP 记录（IPv4 且规模允许时）
  4. 写入网段记录

错误响应 ​

HTTP场景message 示例
400缺少必填字段缺少必填字段：name 和 cidr
400网段冲突新网段与已有网段 生产网 (10.0.0.0/24) 存在冲突
400父网段不存在指定的父网段不存在

获取网段详情 ​

http
GET /api/ipam/subnets/{id}

返回网段自身的全部字段 加上 自身及全部后代网段的 IP 统计累加值。

附加字段说明
freeCount / usedCount / reservedCount / gatewayCount / excludedCount各状态 IP 数量
totalIpsIP 总数
usageRate使用率（usedCount / usableHosts）
childCount直接子网段数量

统计为「累加值」：查询父网段时会递归收集所有后代网段并汇总，因此父网段的已用数包含子网段的已用数。

更新网段 ​

http
PUT /api/ipam/subnets/{id}

支持修改名称、网关、DNS、VLAN、用途、备注等字段。修改 CIDR 时会重新执行冲突检测。

删除网段 ​

http
DELETE /api/ipam/subnets/{id}

存在已绑定设备的 IP 时默认拒绝删除，需先解绑。

网段 IP 统计 ​

http
GET /api/ipam/subnets/{id}/stats

按需生成统计数据（对大规模网段避免全量扫描），返回结构与网段详情中的统计字段一致。

网段内 IP 列表 ​

http
GET /api/ipam/subnets/{id}/ips

查询参数 ​

参数类型必填说明
statusstring否按 IP 状态筛选
ipTypestring否按 IP 类型筛选
keywordstring否按地址 / 标签 / 自定义标签模糊匹配
pagenumber否页码，默认 1
pageSizenumber否每页条数

IP 地址管理 ​

全局查询 IP 列表 ​

http
GET /api/ipam/ips

用于设备侧反向查询，或跨网段检索 IP。

查询参数 ​

参数类型必填说明
deviceIdstring否按绑定设备筛选
ipTypestring否按 IP 类型筛选
statusstring否按状态筛选
keywordstring否按 IP 地址 / label / customTag 模糊匹配
sortOrderstring否asc（默认）或 desc，按 ipInt128 排序，IPv4 与 IPv6 混排正确
pagenumber否页码，默认 1
pageSizenumber否每页条数，默认 50

响应示例 ​

json
{
  "success": true,
  "data": {
    "list": [
      {
        "ipId": "IPM3K8X2A1B4C7",
        "ipAddress": "10.10.1.21",
        "status": "used",
        "ipType": "management",
        "isPrimaryForDevice": true,
        "deviceId": "SRV-0001",
        "Device": { "deviceId": "SRV-0001", "name": "计算节点 01", "type": "server" }
      }
    ],
    "pagination": { "page": 1, "pageSize": 50, "total": 1, "totalPages": 1 }
  }
}

注意：IPAM 的分页信息位于 data.pagination，与系统通用分页结构（data.list / total / page / pageSize）不同。

获取 IP 详情 ​

http
GET /api/ipam/ips/{id}

更新 IP ​

http
PUT /api/ipam/ips/{id}

可更新字段 ​

字段说明
ipTypeIP 类型
customTag自定义标签
isPrimaryForDevice设为主 IP（设置后同设备其它 IP 自动取消主 IP 标记）
status手动变更状态；变更后 statusAutoDriven 自动置为 false，解绑时不再自动回退
label / description标签与备注

校验规则

  • 已绑定设备的 IP 不允许改为 gateway 或 excluded
  • 手动修改状态会解除「自动驱动」标记，后续解绑不会回退为 free

绑定 IP 到设备 ​

http
PATCH /api/ipam/ips/{id}/bind

v2.8.3 新增，全流程在数据库事务中执行。

请求体 ​

字段类型必填说明
deviceIdstring是目标设备编号，必须存在
ipTypestring否绑定时指定 IP 类型，未传则沿用网段 purpose 推荐值
customTagstring否自定义标签
setPrimaryboolean否是否同时设为主 IP，默认 false

行为说明 ​

行为说明
状态驱动绑定后若 IP 原状态为 free，自动改为 used 并置 statusAutoDriven = true
主 IP 互斥setPrimary = true 时，同设备其它 IP 的 isPrimaryForDevice 自动置 false
回滚任一步失败整体回滚

错误响应 ​

HTTP场景
400缺少 deviceId
400设备不存在：设备 SRV-9999 不存在
404IP 不存在

解绑 IP ​

http
PATCH /api/ipam/ips/{id}/unbind

清除 deviceId、networkCardId 与主 IP 标记；若 statusAutoDriven = true，状态自动回退 free 并将标记复位。

批量绑定 ​

http
POST /api/ipam/ips/batch-bind

请求体 ​

字段类型必填说明
ipIdsarray是待绑定的 IP ID 列表
deviceIdstring是目标设备编号
ipTypestring否统一指定的 IP 类型
customTagstring否统一标签

单条 IP 绑定失败时不会中断整批，响应中返回逐条结果。

字段类型必填说明
ipIdsarray是IP ID 列表
statusstring否统一设置的状态
labelstring否统一标签
ipTypestring否统一 IP 类型
customTagstring否统一自定义标签

批量创建 IP ​

http
POST /api/ipam/ips/batch-create

在指定网段内按地址范围批量创建 IP 记录（用于大网段按需生成）。

删除 IP ​

DELETE /api/ipam/ips/{id}

已绑定设备的 IP 需先解绑。

IP 全局搜索 ​

http
GET /api/ipam/search

跨网段、跨设备的关键字搜索，用于快速定位某个地址或设备链路。

在线探测 ​

IP 在线探测用于感知地址存活状态，结果写入 probeStatus / probeMethod / probeLatency 字段。

探测配置 ​

http
GET /api/ipam/probe/config
PUT /api/ipam/probe/config

可配置项 ​

字段类型默认值说明
enablePingbooleantrue是否启用 ICMP Ping 探测
tcpPortsarray | string[22, 80, 443, 161, 3389]Ping 失败时的 TCP 回退探测端口，支持 "22,80,443" 字符串形式
timeoutMsnumber1500单个目标探测超时（毫秒），最小 200
concurrencynumber20并发数，范围 1~100

配置持久化于系统设置表 ipam_probe_config。

定时探测调度 ​

http
GET /api/ipam/probe/schedule
PUT /api/ipam/probe/schedule

字段 ​

字段类型默认值说明
enabledbooleanfalse定时探测开关
expressionstring0 3 * * *Cron 表达式，默认每天凌晨 3 点

支持只提交其中一个字段，未提交字段保持原值；保存后调度器热重载立即生效。

手动触发全量探测 ​

http
POST /api/ipam/probe/run-once

立即执行一次全量探测任务（异步执行，返回任务受理结果）。

单地址探测 ​

http
POST /api/ipam/probe/single

请求体 ​

字段类型必填说明
ipAddressstring是待探测地址

批量地址探测 ​

http
POST /api/ipam/probe/batch

请求体 ​

字段类型必填说明
ipAddressesarray是待探测地址列表（建议单批不超过并发数 × 10）

按网段探测 ​

http
POST /api/ipam/probe/subnet/{subnetId}

对指定网段内所有 IP 执行探测。

设备删除的级联处理 ​

v2.8.3 起，删除设备时系统自动：

  1. 解绑该设备关联的所有 IP（清空 deviceId、networkCardId、isPrimaryForDevice）
  2. 对 statusAutoDriven = true 的 IP 自动回退为 free
  3. 用户手动设置过状态的 IP 保持原状态不变

旧字段迁移说明 ​

v2.8.3 将 Device.ipAddress 旧字段迁移至 IpAddress 表（ipType = management、status = used、subnetId = NULL）。旧字段保留但已废弃，新代码不应再依赖 Device.ipAddress。

数据库迁移脚本位于 backend/scripts/migrations/，通过 npm run migrate 幂等执行。

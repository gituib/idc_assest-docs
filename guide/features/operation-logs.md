# 操作日志

操作日志用于审计系统中所有用户操作记录。

![操作日志概览](/images/screenshots/operation-logs.png)

## 功能说明

| 功能 | 说明 |
|------|------|
| **日志查询** | 按时间范围、操作模块、操作类型筛选 |
| **模块列表** | 查看系统所有操作模块（设备管理、用户管理、耗材管理、备份管理、端口管理、空闲设备、认证管理、系统设置、线缆管理、网卡管理、库房管理等） |
| **操作类型** | 查看所有操作类型（创建/更新/删除/导入/导出/登录/登出/入库/出库/解锁/上架/转入空闲/批量操作等30+种） |
| **操作统计** | 按模块、操作类型、操作人维度统计操作次数，支持日趋势图表 |
| **日志详情** | 查看单条操作的完整信息（请求参数、响应状态、耗时、User-Agent 等） |

## 操作说明

1. 进入「操作日志」页面
2. 使用筛选条件缩小查询范围：时间范围、操作模块、操作类型
3. 点击日志条目查看详细信息
4. 可查看操作统计图表

# 空闲设备管理

空闲设备管理用于管理当前未上架或暂时不使用的设备。

> **v2.2.0 更新**：新增空闲设备列表与详情展示页面，支持按资产编号、设备名称、设备型号搜索筛选；移除表单中的资产状态和入库日期字段，优化数据录入体验。

## 功能说明

- 查看所有空闲设备列表，支持搜索筛选
- 查看空闲设备详情信息
- 将运行中设备转入空闲状态
- 将空闲设备重新激活上架

## 搜索筛选

v2.2.0 新增，支持多维度快速查找空闲设备：

| 筛选条件 | 说明 |
|----------|------|
| **资产编号** | 按设备资产编号精确/模糊搜索 |
| **设备名称** | 按设备名称关键词搜索 |
| **设备型号** | 按设备型号关键词搜索 |

操作方式：在空闲设备列表页顶部的搜索栏中输入关键词，点击「搜索」按钮或按回车键即可筛选结果。

## 操作流程

### 设备转入空闲

1. 在设备管理页面，选择需要转入空闲的设备
2. 点击「转入空闲」按钮
3. 确认操作后，设备状态变为空闲
4. 在「空闲设备」页面查看所有空闲设备

### 空闲设备激活

1. 进入「空闲设备」页面
2. 通过搜索筛选找到目标设备
3. 点击设备行进入详情页查看完整信息
4. 确认无误后点击「激活」按钮
5. 填写上架信息（机房、机柜、U位等）后提交，设备恢复为运行状态

系统管理 ​

用户管理 ​

用户管理用于管理系统用户账号和权限。

用户状态 ​

状态说明
正常用户可正常登录系统并使用相应权限功能
待审核新注册用户，等待管理员审核通过后方可登录
已禁用账号被管理员禁用，无法登录系统

审核流程 ​

用户注册审核流程如下：

  1. 用户注册：新用户通过注册页面提交账号信息
  2. 待审核状态：注册成功后，账号自动进入「待审核」状态
  3. 管理员审核：管理员在「用户管理」页面查看待审核用户列表
  4. 审核操作：管理员可「通过」或「驳回」注册申请，驳回需填写原因
  5. 结果通知：
    • 审核通过：用户收到通知，账号状态变更为「正常」，可登录系统
    • 审核驳回：用户收到通知及驳回原因，可根据原因修改后重新提交注册

角色权限 ​

系统采用 RBAC（基于角色的访问控制）权限模型：

角色权限范围
管理员（admin）全部功能（通配符 *），包括系统设置、用户管理、数据管理、所有模块的增删改查
运维人员设备管理（含导入导出、端口管理、接线管理）、工单处理（接单、处理、完成）
普通用户查看权限（查看设备、工单、仪表盘等），可创建工单

角色管理 ​

v2.4.0 新增「角色管理」独立页面，支持管理员自定义角色与权限分配。

角色管理页面提供可视化的角色与权限配置功能：

角色列表 ​

进入「系统管理」→「角色管理」，可查看系统所有角色：

  • 角色名称、角色编码、状态、创建时间
  • 支持按角色名称搜索、按状态筛选
  • 支持新增、编辑、删除角色
  • 删除角色时需确保没有用户关联该角色

创建/编辑角色 ​

配置项说明
角色名称角色显示名称，如「审计员」、「网络管理员」
角色编码角色唯一标识（如 auditor），创建后不可修改
排序控制角色在列表中的显示顺序
状态启用/禁用，禁用后该角色下所有用户权限失效

权限配置 ​

系统采用 三级权限结构（模块→菜单→按钮），创建角色时按需勾选：

模块级（第一层）       菜单级（第二层）        按钮级（第三层）
────────────────────────────────────────────────────
仪表盘                ├─ 查看仪表盘           └─ 导出数据
机房管理              ├─ 机房列表              ├─ 查看机房
                      │                       ├─ 新增机房
                      │                       ├─ 编辑机房
                      │                       └─ 删除机房
                      ├─ 机柜列表              ├─ 查看机柜
                      │                       ├─ 新增机柜
                      │                       └─ ...
                      ├─ 3D机柜可视化
                      └─ 机房平面图            └─ 编辑平面图
资产管理              ├─ 设备管理              ├─ 查看/新增/编辑/删除设备
                      │                       ├─ 导入/导出设备
                      ├─ 空闲设备              ├─ 上架/编辑/恢复/删除
                      ├─ 字段管理
                      ├─ 端口管理              ├─ 新增/编辑/删除端口
                      └─ 接线管理              ├─ 新增/编辑/删除接线
耗材管理              ├─ 耗材管理              ├─ ...
                      ├─ 耗材分类
                      └─ 耗材统计
工单管理              ├─ 工单管理              ├─ ...
                      └─ 工单统计
资产盘点              ├─ 盘点任务              ├─ ...

系统管理              ├─ 用户管理              ├─ 查看/新增/编辑/删除用户
                      ├─ 角色管理              ├─ 查看/新增/编辑/删除角色
                      ├─ 系统设置              ├─ 查看/编辑设置

操作日志              ├─ 操作日志              └─ ...
备份管理              ├─ 备份管理              └─ ...
库房管理              ├─ 库房管理              └─ ...
  • 父子联动：勾选父级权限时，自动勾选其下所有子权限；取消子权限时，父级保持选中
  • 通配符支持：* 表示全部权限，inventory:* 表示盘点模块下的所有权限
  • 管理员角色：默认拥有所有权限（通配符 *），不可编辑权限范围

角色分配 ​

在「用户管理」→「编辑用户」页面中，通过多选下拉框为用户分配角色：

  • 单用户多角色：用户权限 = 所有角色权限的并集
  • 变更即生效：角色分配修改后，用户下次请求时自动生效（无需重新登录）

系统设置 ​

系统设置用于配置系统全局参数，包含「基本设置」「邮件服务」「关于系统」三个标签页。

基本设置 ​

基本设置包含站点信息、公司信息、安全设置等通用配置。

站点信息 ​

设置项说明
站点名称系统浏览器标签页标题和页面左上角显示的名称
Logo系统左上角显示的 Logo 图片，建议尺寸 120×40px，支持 PNG/SVG 格式

安全设置 ​

设置项说明
空闲超时用户无操作后自动退出登录的时间，可选范围：15分钟、30分钟、60分钟、永不超时
背景图片登录页的背景图片，支持 JPG/PNG 格式
维护模式开启后系统仅管理员可登录，其他用户访问时显示维护提示页面
登录限制可限制指定 IP 段或仅允许内网 IP 访问系统登录页

邮件服务（管理员专属） ​

v2.3.0 新增，仅管理员可见此标签页。

邮件服务用于配置 SMTP 邮件发送，支持发送验证码邮件、测试邮件等功能。

配置项 ​

设置项说明
SMTP 服务器邮件发送服务器地址（如 smtp.example.com）
端口SMTP 服务端口（465/587/25 等）
加密方式SSL/TLS 加密方式
发件人邮箱发件人邮箱地址
发件人名称邮件发件人显示名称
SMTP 用户名邮箱登录用户名
SMTP 密码邮箱登录密码或授权码

操作说明 ​

  1. 进入「系统管理」→「系统设置」→「邮件服务」标签
  2. 填写 SMTP 服务器配置信息
  3. 点击「保存」完成配置
  4. （可选）点击「发送测试邮件」验证配置是否生效

关于系统 ​

关于系统页面提供系统版本信息和相关工具。

系统信息 ​

  • 系统名称：IDC 设备资产管理系统
  • 当前版本：显示当前运行的版本号
  • 部署环境：显示是否运行在 Docker 容器中

系统监控 ​

v2.3.4 新增。系统首页「系统信息」卡片展示实时运行状态。

系统监控信息通过系统设置页面「关于系统」标签页查看：

指标说明
CPU 使用率基于 os.cpus().times 差值计算，每 5 秒采样一次，跨平台准确获取
内存使用率系统内存总量、已用、可用及百分比
磁盘使用率系统磁盘空间概览
数据库状态数据库类型（MySQL / SQLite）、版本号、连接状态
运行时长进程已运行时间
Node.js 版本运行环境版本

CPU 使用率采样器替代了 os.loadavg()（Windows 上始终返回 [0,0,0]），采用真实差值计算，确保 Linux 和 Windows 均准确。

在线更新 ​

v2.3.2 新增。

点击「检查更新」按钮，系统自动检测是否有新版本可用：

  • 已是最新：绿色标识提示已是最新版本
  • 发现新版本：显示当前版本与最新版本对比，并提供更新指引
    • 非 Docker 环境：显示终端命令提示（cd 项目路径 && node update.js），支持一键复制
    • Docker 环境：提示拉取最新镜像后重建容器
  • 更新日志区域展示版本发布说明

开源许可 ​

v2.3.2 新增。

点击「开源许可」按钮，可查看系统前后端所有依赖包的开源许可信息：

  • 按许可类型分组统计（MIT、Apache-2.0、ISC 等）
  • 列表展示：依赖名称、版本、许可类型、运行/开发分类、项目主页
  • 支持分页浏览

操作说明 ​

  1. 进入「系统管理」→「系统设置」页面
  2. 通过左侧标签导航切换不同设置模块
  3. 修改配置项后点击「保存」按钮
  4. 部分设置（如站点名称、Logo、空闲超时）保存后立即生效
  5. 维护模式和登录限制等安全设置保存后，下一次登录时生效

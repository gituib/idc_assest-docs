# 备份管理

备份管理用于数据库的备份与恢复，保障数据安全。

![备份管理概览](/images/screenshots/backup-management.png)

## 备份管理

### 手动备份

1. 进入「备份管理」→「备份管理」页面
2. 点击「创建备份」按钮
3. 填写备份名称和描述（选填）
4. 系统自动创建数据库备份文件
5. 备份完成后显示在备份列表中，包含备份时间、文件大小、类型等信息

### 备份恢复

1. 在备份列表中选择要恢复的备份文件
2. 点击「恢复」按钮
3. 仔细阅读恢复提示（恢复会覆盖当前数据）
4. 系统显示恢复进度，完成后自动重启服务

> 恢复前建议先对当前数据进行手动备份。

### 备份文件管理

| 操作 | 说明 |
|------|------|
| **上传** | 上传外部备份文件到服务器，支持跨环境恢复 |
| **下载** | 下载备份文件到本地保存 |
| **删除** | 删除不需要的备份文件 |
| **验证** | 校验备份文件的完整性和可用性（显示表数量和记录数） |
| **清理** | 批量清理旧备份，支持按保留份数和天数设置 |

## 自动备份

配置 Cron 表达式设置备份执行时间，支持保留备份文件数量设置。启用自动备份后，系统按设定时间自动创建备份。

## 远端备份

支持将备份文件自动传输到远端存储，协议包括 FTP、SFTP、WebDAV、SMB。

### 远端配置

1. 进入「远端备份」标签
2. 点击「添加配置」，填写远端存储信息
3. 点击「测试连接」验证配置
4. 测试通过后保存配置

### 手动同步

选择本地备份文件，手动触发上传到远端存储。

# 用户使用指南

## 系统概述

IDC设备资产系统是一款现代化的数据中心（IDC）设备管理平台，提供机房、机柜、设备的全生命周期管理，具备3D可视化展示功能。本文档将详细介绍每个功能模块的具体操作流程。

![系统登录页面](/images/screenshots/login-page.png)

---

## 一、账号管理

### 1.1 用户注册

系统部署完成后，第一个注册的用户自动成为管理员，拥有全部权限。

**操作步骤：**

1. 打开系统登录页面
2. 点击登录框下方的「立即注册」按钮
3. 在注册表单中填写以下信息：
   - **用户名**：3-20个字符，支持字母、数字、下划线
   - **密码**：至少8位，建议包含大小写字母、数字和特殊字符
   - **确认密码**：再次输入密码以确认
   - **真实姓名**：填写真实姓名，便于管理识别
   - **联系电话**：选填，便于紧急联系
   - **邮箱**：选填，用于接收系统通知
4. 点击「注册」按钮提交
5. 注册成功后，账号状态为「待审核」，等待管理员审核通过

> **注意**：首个注册用户无需审核，自动成为管理员。

### 1.2 用户登录

**操作步骤：**

1. 打开系统网址，进入登录页面
2. 在「用户名」输入框填写您的账号
3. 在「密码」输入框填写登录密码
4. （可选）勾选「记住我」，下次访问自动填充账号
5. 点击「登 录」按钮

**登录异常处理：**

| 提示信息 | 原因 | 解决方法 |
|----------|------|----------|
| 用户名或密码错误 | 账号或密码输入有误 | 检查输入，注意大小写区分 |
| 账号待审核 | 注册后管理员尚未审核 | 联系管理员进行审核 |
| 账号已禁用 | 管理员禁用了该账号 | 联系管理员咨询原因 |
| 账号已锁定 | 连续3次登录失败 | 等待15分钟后自动解锁，或联系管理员 |

### 1.3 密码重置

如果忘记密码，请联系系统管理员在「用户管理」中重置密码。

### 1.4 退出登录

- 点击页面右上角的「退出」按钮
- 确认退出后，系统返回登录页面
- 系统默认30分钟无操作自动退出，退出前1分钟会有提示

### 2.2 菜单操作

- **展开/折叠菜单**：点击左上角的菜单折叠按钮，可切换为图标模式，为内容区域提供更宽空间
- **展开子菜单**：点击带箭头的父级菜单（如「资产管理」），展开子菜单项
- **页面跳转**：点击具体菜单项，右侧内容区域加载对应页面
- **当前位置标识**：当前所在页面的菜单项会高亮显示

### 2.3 通用列表操作

所有列表页面（设备、耗材、工单等）均支持以下通用操作：

| 操作 | 方法 |
|------|------|
| **搜索** | 在搜索框输入关键词，按回车或点击搜索按钮 |
| **筛选** | 点击筛选条件下拉框，选择筛选值 |
| **高级筛选** | 点击「高级筛选」展开更多筛选条件 |
| **重置筛选** | 点击「重置」按钮清空所有筛选条件 |
| **刷新列表** | 点击「刷新」按钮重新加载数据 |
| **分页** | 点击底部分页按钮切换页码，可选择每页显示数量（10/20/50/100） |
| **勾选** | 点击列表行前的复选框勾选，支持全选 |
| **批量操作** | 勾选多条记录后，顶部批量操作按钮可用 |

## 四、机房管理

机房管理用于维护数据中心的物理基础设施信息，包括机房、机柜管理，以及2D平面图和3D可视化展示。

![机房管理概览](/images/screenshots/room-management.png)

### 4.1 机房管理

#### 4.1.1 新增机房

**操作步骤：**

1. 在左侧菜单点击「机房管理」→「机房管理」
2. 点击页面右上角「新增机房」按钮
3. 在弹出的表单中填写以下信息：
   - **机房名称** *（必填）*：如「机房01」、「A区机房」
   - **位置** *（必填）*：机房所在的物理位置，如「2楼东侧」
   - **面积**（选填）：机房面积，单位平方米
   - **负责人**（选填）：机房运维负责人
   - **联系电话**（选填）：负责人联系电话
   - **备注**（选填）：补充说明信息
   - **机房图片**（选填）：上传机房实景照片，支持JPG/PNG格式
4. 点击「确定」保存
5. 新增成功后，机房出现在列表中

#### 4.1.2 编辑机房信息

1. 在机房列表找到目标机房
2. 点击该行的「编辑」按钮
3. 修改需要更新的信息
4. 点击「确定」保存修改

#### 4.1.3 删除机房

::: warning 注意
删除机房前必须先删除或迁移该机柜下的所有机柜和设备，否则无法删除。
:::

1. 在机房列表找到目标机房
2. 确认该机房下已无机柜和设备
3. 点击该行的「删除」按钮
4. 在确认对话框中点击「确定」
5. 机房删除成功

#### 4.1.4 查看机房详情

点击机房名称可进入机房详情页，查看该机柜的机柜列表、平面图、设备统计等信息。

### 4.2 机柜管理

#### 4.2.1 新增机柜

**操作步骤：**

1. 在左侧菜单点击「机房管理」→「机柜管理」（或在机房详情页点击「新增机柜」）
2. 点击「新增机柜」按钮
3. 填写机柜信息：
   - **机柜名称** *（必填）*：如「R01」、「A01-C05」
   - **所属机房** *（必填）*：从下拉列表选择所在机房
   - **机柜高度(U数)** *（必填）*：标准机柜通常为42U
   - **位置编码**（选填）：机柜在机房中的物理位置编号
   - **额定功率**（选填）：机柜供电额定功率，单位kW
   - **备注**（选填）：补充说明
4. 点击「确定」保存

#### 4.2.2 查看机柜容量

机柜列表显示以下容量信息：
- **总U数**：机柜的总U位数量
- **已用U数**：已被设备占用的U位数量
- **剩余U数**：可使用的空闲U位数量
- **使用率**：以可视化进度条展示，颜色标识：
  - 🟢 绿色：使用率 < 60%
  - 🟡 黄色：使用率 60% ~ 85%
  - 🔴 红色：使用率 > 85%

#### 4.2.3 批量导入机柜

适用于一次性创建大量机柜的场景：

1. 点击「导入」按钮
2. 在弹出窗口中点击「下载模板」
3. 打开下载的Excel/CSV模板，按要求填写：
   - 机柜名称、所属机房、机柜高度（U数）、位置编码
4. 保存填写好的模板文件
5. 点击「上传文件」，选择填写好的模板
6. 系统自动解析并导入，显示导入结果：
   - 成功数量：成功创建的机柜数
   - 失败数量：导入失败的记录数及失败原因
7. 导入完成后关闭窗口

#### 4.2.4 批量导出机柜

1. （可选）设置筛选条件，只导出符合条件的机柜
2. 点击「导出」按钮
3. 选择导出格式：Excel 或 CSV
4. 文件自动下载到本地

### 4.3 机房平面图

机房平面图以2D俯视图展示机房物理布局。

**操作方式：**

| 操作 | 方法 |
|------|------|
| 缩放视图 | 鼠标滚轮向上放大，向下缩小 |
| 平移视图 | 鼠标拖拽空白区域移动 |
| 查看机柜信息 | 点击机柜图标，弹出详情面板 |
| 查看设备统计 | 鼠标悬停在机柜上，显示设备数量和使用率 |

**编辑平面图：**

1. 进入机房详情页，切换到「平面图」标签
2. 点击「编辑平面图」按钮进入编辑模式
3. 可执行以下操作：
   - 拖拽机柜调整位置
   - 添加区域标注（服务器区、网络区、配电区等）
   - 标注冷/热通道方向
   - 添加基础设施标记（空调、UPS、配电柜等）
4. 编辑完成后点击「保存」
5. 如需放弃修改，点击「取消」

### 4.4 3D机柜可视化

3D可视化提供逼真的机柜设备布局展示。

**进入方式：**
- 在左侧菜单点击「机房管理」→「3D机柜可视化」
- 或在机柜详情页点击「3D视图」按钮

**操作方式：**

| 操作 | 方法 |
|------|------|
| 旋转视角 | 按住鼠标左键拖拽 |
| 缩放视图 | 鼠标滚轮向上放大，向下缩小 |
| 平移视图 | 按住鼠标右键拖拽 |
| 查看设备信息 | 鼠标悬停在设备上，显示名称、类型、状态等 |
| 查看设备详情 | 点击设备，弹出详情面板 |
| 搜索定位 | 在搜索框输入设备名称，自动聚焦并高亮 |
| 切换机柜 | 点击机柜列表选择要查看的机柜 |

**设备状态颜色标识：**

| 颜色 | 状态 |
|------|------|
| 🟢 绿色 | 运行中 |
| 🟡 黄色 | 维护中 |
| 🔴 红色 | 故障/离线 |
| ⚪ 灰色 | 已报废/停用 |

## 五、资产管理

资产管理是系统核心模块，提供设备、端口、接线的全生命周期管理。

![设备管理概览](/images/screenshots/device-management.png)

### 5.1 设备管理

#### 5.1.1 设备状态说明

设备在生命周期中会在以下状态间流转：

```
采购中 → 待安装 → 运行中 ⇄ 维护中 → 已报废
```

| 状态 | 说明 |
|------|------|
| **采购中** | 设备已下单采购，尚未到货 |
| **待安装** | 设备已到货，等待上架安装 |
| **运行中** | 设备已安装到位，正常运行 |
| **维护中** | 设备正在进行维护保养 |
| **已报废** | 设备已达到使用年限或故障无法修复，做报废处理 |

#### 5.1.2 单个新增设备

**操作步骤：**

1. 在左侧菜单点击「资产管理」→「设备管理」
2. 点击页面右上角「添加设备」按钮
3. 在表单中填写设备信息：

   **基础信息：**
   - **设备名称** *（必填）*：建议命名规范如「机房01-R01-D01」
   - **设备类型** *（必填）*：服务器、交换机、路由器、存储、防火墙、其他
   - **型号**（选填）：设备具体型号，如「Dell R740」
   - **序列号** *（必填）*：设备唯一序列号SN
   - **品牌**（选填）：设备品牌
   - **资产编号**（选填）：公司内部资产编号

   **位置信息：**
   - **所属机房** *（必填）*：选择所在机房
   - **所在机柜** *（必填）*：选择该机柜下的机柜
   - **起始U位** *（必填）*：设备安装的起始U位
   - **设备高度(U)** *（必填）*：设备占用的U位数量，1U/2U/4U等

   **管理信息：**
   - **状态** *（必填）*：选择当前状态
   - **管理IP**（选填）：设备带外管理IP（iLO/iDRAC/BMC等）
   - **业务IP**（选填）：业务网IP地址
   - **负责人**（选填）：设备责任人
   - **购买日期**（选填）：设备采购日期
   - **过保日期**（选填）：保修到期日期
   - **备注**（选填）：补充说明

4. 点击「确定」保存
5. 新增成功后设备出现在列表中

#### 5.1.3 批量导入设备

适用于一次性录入大量设备：

1. 点击「导入」按钮
2. 下载导入模板（Excel/CSV格式）
3. 按模板要求填写设备信息（红色列为必填项）
4. 保存文件
5. 点击「上传文件」，选择填写好的模板
6. 系统预览待导入数据，确认无误后点击「确认导入」
7. 查看导入结果，处理失败记录

#### 5.1.4 编辑设备信息

1. 在设备列表找到目标设备
2. 点击设备名称进入详情页，或点击「编辑」按钮
3. 修改需要更新的信息
4. 点击「确定」保存

#### 5.1.5 设备上下架

**设备上架（安装）：**
1. 新增设备时状态选择「待安装」
2. 设备实际上架安装后，编辑设备将状态改为「运行中」
3. 填写位置信息（机柜、U位）

**设备下架（报废）：**
1. 确认设备已断电下架
2. 编辑设备，将状态改为「已报废」
3. （可选）在备注中记录报废原因和处置方式

#### 5.1.6 删除设备

1. 在设备列表找到目标设备
2. 点击该行的「删除」按钮
3. 阅读删除提示，确认删除
4. 点击「确定」

::: danger 危险操作
设备删除后无法恢复，请确认设备已报废或不再需要管理后再删除。建议优先使用「已报废」状态而非删除。
:::

#### 5.1.7 批量操作设备

勾选多条设备后，可执行以下批量操作：

| 操作 | 说明 |
|------|------|
| **状态变更** | 批量修改设备状态（如批量标记为维护中） |
| **维保更新** | 批量更新设备过保日期 |
| **标记为空闲** | 将选中设备标记为空闲设备 |
| **批量删除** | 批量删除选中的设备（谨慎操作） |

**操作步骤：**
1. 在列表中勾选要操作的设备（可跨页选择）
2. 点击顶部对应批量操作按钮
3. 在弹出窗口中填写修改内容
4. 点击「确定」执行

#### 5.1.8 导出设备

1. （可选）设置筛选条件
2. 勾选要导出的设备，或不勾选导出全部
3. 点击「导出」按钮
4. 选择导出格式：Excel 或 CSV
5. 文件自动下载

#### 5.1.9 查看设备详情

点击设备名称进入详情页，可查看：
- 设备基础信息
- 端口列表及状态
- 接线关系
- 关联的工单历史
- 操作日志

### 5.2 端口管理

端口管理用于配置设备的网络端口信息。

![端口管理概览](/images/screenshots/port-management.png)

#### 5.2.1 端口类型说明

| 类型 | 说明 | 示例 |
|------|------|------|
| **网口** | RJ45以太网电口 | eth0, GigabitEthernet0/0/1 |
| **光口** | SFP/SFP+/QSFP光纤接口 | TenGigabitEthernet1/0/1 |
| **管理口** | 带外管理接口 | iLO, iDRAC, BMC |

#### 5.2.2 新增端口

单个新增：
1. 进入设备详情页，切换到「端口管理」标签
2. 点击「新增端口」按钮
3. 填写端口信息：
   - **端口名称** *（必填）*：如eth0
   - **端口类型** *（必填）*：选择端口类型
   - **MAC地址**（选填）：端口物理地址
   - **速率**（选填）：协商速率，如1000Mbps、10Gbps
   - **连接状态**：未连接/已连接
   - **备注**（选填）
4. 点击「确定」保存

批量新增：
1. 点击「批量添加端口」
2. 输入端口范围（如eth0-eth47）
3. 选择端口类型
4. 点击「确定」，系统自动创建该范围的端口

#### 5.2.3 编辑端口

1. 在端口列表找到目标端口
2. 点击「编辑」按钮
3. 修改端口信息
4. 点击「确定」保存

#### 5.2.4 批量操作端口

**批量编辑：**
1. 勾选多个端口（支持跨设备选择）
2. 点击「批量编辑」按钮
3. 选择要修改的属性，填写新值
4. 点击「确定」批量更新

**批量清理：**
1. 勾选要清理的端口
2. 点击「批量清理」按钮
3. 确认后，系统清除这些端口的网卡绑定和备注信息

#### 5.2.5 绑定网卡

1. 点击端口的「绑定网卡」按钮
2. 在弹出窗口中搜索并选择要绑定的网卡设备
3. 点击「确定」完成绑定
4. 绑定后可在网卡详情页查看关联端口

#### 5.2.6 分组预览

端口列表默认按设备分组展示：
- 每个设备可折叠/展开
- 分组头部显示设备名称、端口总数、已连接/未连接数量
- 支持按端口类型、连接状态快速筛选

### 5.3 接线管理

接线管理用于记录设备间的线缆连接关系。

#### 5.3.1 创建接线

**操作步骤：**

1. 进入设备详情页，切换到「接线管理」标签（或在左侧菜单进入「接线管理」）
2. 点击「新增接线」按钮
3. 填写接线信息：
   - **源设备** *（必填）*：选择起始端设备
   - **源端口** *（必填）*：选择源设备上的端口
   - **目标设备** *（必填）*：选择终止端设备
   - **目标端口** *（必填）*：选择目标设备上的端口

   - **线缆编号**（选填）：物理线缆标签编号
   - **长度(米)**（选填）：线缆物理长度

**跳线引导功能：**

- 仅显示未建立连接的可用端口
- 按设备分组展示
- 可按线缆类型筛选（如选光纤只显示光口）

#### 5.3.2 查看接线关系

- 点击接线记录可查看详情
- 支持按线缆类型筛选

#### 5.3.3 连接追踪

系统支持对连接进行可视化追踪：
- **正向追踪**：从指定端口出发，查看连接到哪些设备
- **反向追踪**：查看哪些设备连接到当前端口
- **全链路追踪**：展示完整的端到端链路路径

**操作：**
1. 在接线列表找到目标接线
2. 点击「追踪」按钮
3. 拓扑图中高亮显示追踪路径

#### 5.3.4 删除接线

1. 在接线列表找到目标记录
2. 点击「删除」按钮

#### 5.3.5 导出接线清单

1. 在接线管理页面设置筛选条件（按机房、设备、线缆类型等）
2. 点击「导出接线清单」按钮
3. 选择导出格式
4. 导出包含源设备、源端口、目标设备、目标端口、线缆编号、类型、长度等信息的表格

### 5.4 网络拓扑

网络拓扑以可视化图形展示设备间的连接关系。

## 六、耗材管理

耗材管理用于管理数据中心的备件耗材库存，包括出入库、领用、SN序列号追踪等功能。

![耗材管理概览](/images/screenshots/consumable-management.png)

### 6.1 耗材统计

进入耗材管理默认显示统计页面，提供：
- **库存总览**：耗材品类总数、总库存价值、预警数量
- **分类统计**：按分类展示库存数量和占比
- **库存预警**：低于安全库存的耗材列表
- **领用趋势**：近期出入库趋势图表

### 6.2 耗材列表

#### 6.2.1 新增耗材

**操作步骤：**

1. 点击「耗材列表」标签
2. 点击「新增耗材」按钮
3. 填写耗材信息：
   - **名称** *（必填）*：如「1TB SATA硬盘」
   - **分类** *（必填）*：选择耗材分类（硬盘、内存、光模块、网线、电源线等）
   - **规格**（选填）：详细规格参数
   - **计量单位** *（必填）*：个、块、条、箱等
   - **库存数量** *（必填）*：初始库存数量
   - **安全库存** *（必填）*：低于此数量触发预警
   - **单价**（选填）：单价，用于库存价值统计
   - **SN管理**：是否需要序列号级追踪
   - **备注**（选填）
4. 点击「确定」保存

#### 6.2.2 入库操作

当耗材采购到货后，执行入库操作增加库存：

1. 在耗材列表找到目标耗材
2. 点击「入库」按钮
3. 填写入库信息：
   - **入库数量** *（必填）*：入库的数量
   - **入库单价**（选填）：本次入库单价
   - **供应商**（选填）：供应商名称
   - **入库单号**（选填）：采购入库单编号
   - **SN序列号**（如果开启SN管理）：逐个输入或批量扫描SN码
   - **备注**（选填）
4. 点击「确定」完成入库
5. 库存数量相应增加

#### 6.2.3 出库/领用操作

耗材领用时执行出库操作：

1. 在耗材列表找到目标耗材
2. 点击「出库」按钮
3. 填写出库信息：
   - **出库数量** *（必填）*：领用数量
   - **领用人** *（必填）*：从用户列表选择领用人员
   - **领用部门**（选填）
   - **用途说明**（选填）：领用用途
   - **SN序列号**（如果开启SN管理）：扫描或选择要出库的具体SN
   - **备注**（选填）
4. 点击「确定」完成出库
5. 库存数量相应减少

#### 6.2.4 库存盘点

当需要核实实际库存时，使用盘点功能修正库存数量：

1. 点击耗材的「盘点」按钮
2. 输入实际盘点数量
3. 填写差异原因（如有盘盈盘亏）
4. 点击「确定」，库存数量更新为实际盘点数

#### 6.2.5 SN序列号追踪

对于需要精确管理的耗材（如硬盘、内存、光模块等），开启SN管理后：
- 入库时逐个录入SN序列号
- 出库时扫描具体SN，确保实物与记录一致
- 在耗材详情页可查看每个SN的完整流转记录：
  - 入库时间、供应商
  - 当前状态（在库/已领用/已报废）
  - 领用人员、领用时间
  - 报废时间和原因

SN状态标识：
| 状态 | 标识 |
|------|------|
| 在库 | 🟢 绿色标记 |
| 已领用 | 🟡 黄色标记 |
| 已报废 | 🔴 红色标记 |

### 6.3 分类管理

维护耗材的分类体系：

1. 进入「分类管理」标签
2. 可执行以下操作：
   - **新增分类**：点击「新增分类」，填写分类名称、上级分类（支持多级分类）
   - **编辑分类**：修改分类名称和层级
   - **删除分类**：删除空分类（分类下有耗材时无法删除）
   - **排序**：拖拽调整分类显示顺序

### 6.4 操作日志

查看所有耗材的出入库记录：
- 支持按时间范围、耗材名称、操作类型筛选
- 可查看每次操作的详细信息（操作人、操作时间、数量、前后库存变化）
- 支持导出日志

## 七、工单管理

工单管理用于记录和跟踪数据中心故障处理、设备维护等运维工作。

![工单管理概览](/images/screenshots/ticket-management.png)

### 7.1 工单状态与优先级

#### 7.1.1 工单状态流转

```
待处理 → 处理中 → 已完成 → 已关闭
     ↓         ↓
    已取消    已退回
```

| 状态 | 说明 |
|------|------|
| **待处理** | 新建工单，等待分配处理人 |
| **处理中** | 已接单，正在处理 |
| **已完成** | 问题已解决，等待确认 |
| **已关闭** | 工单确认关闭，流程结束 |
| **已取消** | 工单无需处理，被取消 |
| **已退回** | 处理人退回工单，需要重新分配或补充信息 |

#### 7.1.2 工单优先级

| 优先级 | 说明 | 要求响应时间 |
|--------|------|--------------|
| **紧急** | 严重影响业务运行，如核心设备故障、大面积网络中断 | 立即响应，30分钟内到场 |
| **高** | 重要问题，影响部分业务或存在安全隐患 | 2小时内响应 |
| **中** | 一般问题，不影响核心业务 | 24小时内响应 |
| **低** | 优化建议、咨询类问题 | 一周内处理 |

### 7.2 创建工单

**操作步骤：**

1. 在左侧菜单点击「工单管理」→「工单列表」
2. 点击「新建工单」按钮
3. 填写工单信息：

   **基本信息：**
   - **工单标题** *（必填）*：简要描述问题，如「机房01-R03交换机端口异常」
   - **故障分类** *（必填）*：选择故障类型（硬件故障/网络故障/系统故障/环境故障/安全事件/其他）
   - **优先级** *（必填）*：选择紧急/高/中/低
   - **关联设备**（选填）：点击「选择设备」，勾选故障相关的一台或多台设备
   - **问题描述** *（必填）*：详细描述故障现象、发生时间、影响范围等
   - **附件**（选填）：上传截图、日志文件等辅助排查材料

4. 点击「提交」创建工单
5. 工单创建成功，状态为「待处理」

### 7.3 处理工单流程

完整的工单处理流程如下：

#### 步骤1：接单分配
1. 在工单列表查看「待处理」工单
2. 点击工单标题进入详情页
3. 如果你是处理人，点击「接单」按钮，工单自动分配给你，状态变为「处理中」
4. 如果需要分配给其他人，点击「转派」选择处理人

#### 步骤2：处理记录
1. 在处理过程中，随时点击「添加处理记录」
2. 填写处理进展、排查过程、临时措施等
3. 可上传处理过程中的截图或文件
4. 系统自动记录处理人、处理时间

#### 步骤3：暂停/退回（如需）
- 如果需要等待配件、等待其他人员配合，可点击「暂停」并说明原因
- 如果工单信息不足或不属于自己处理范围，点击「退回」并填写退回原因

#### 步骤4：完成工单
1. 问题解决后，点击「完成」按钮
2. 填写解决方案、根因分析、预防措施等
3. （可选）关联相关的设备维护记录
4. 提交后工单状态变为「已完成」

#### 步骤5：关闭工单
1. 工单创建人或管理员确认问题解决后
2. 点击「关闭工单」
3. 填写关闭意见
4. 工单关闭，流程结束

### 7.4 工单关联设备

工单与设备关联后可实现双向追溯：
- **工单详情**：顶部展示关联设备列表，点击设备名称可快速跳转
- **设备详情**：在「工单历史」标签可查看该设备的所有历史工单
- **解除关联**：在工单详情点击设备旁的「解除关联」可移除关联关系

### 7.5 故障分类管理

管理员可维护故障分类体系：

1. 进入「工单管理」→「故障分类」
2. 可执行以下操作：
   - 新增一级/二级分类
   - 编辑分类名称
   - 拖拽调整分类顺序
   - 删除未使用的分类
3. 默认分类建议：
   - 硬件故障（硬盘/内存/电源/风扇/主板故障）
   - 网络故障（端口Down/链路中断/带宽异常/DNS问题）
   - 系统故障（系统崩溃/服务异常/配置错误）
   - 环境故障（温湿度/漏水/供电异常）
   - 安全事件（异常登录/病毒告警/DDoS）

### 7.6 统计报表

进入「统计报表」标签查看工单数据分析：

| 报表类型 | 展示内容 |
|----------|----------|
| 工单数量趋势 | 按日/周/月展示工单创建量变化折线图 |
| 分类统计 | 按故障分类统计数量饼图/柱状图 |
| 处理效率 | 平均响应时间、平均处理时长、按时完成率 |
| 人员统计 | 按处理人统计工单数量、完成率、平均时长 |
| 优先级分布 | 各优先级工单数量分布 |
| 状态分布 | 各状态工单数量统计 |

**报表操作：**
- 选择时间范围（近7天/近30天/近90天/自定义）
- 按分类、优先级、处理人筛选
- 点击图表数据点可钻取查看详细工单列表
- 支持导出为图片或Excel

### 7.7 工单字段管理

与设备字段管理类似，支持自定义工单字段，操作方式参见「5.6 字段管理」。

## 八、资产盘点

资产盘点用于定期对数据中心设备进行实物盘点，确保账实相符。

![资产盘点概览](/images/screenshots/inventory-management.png)

### 8.1 盘点计划管理

#### 8.1.1 创建盘点计划

**操作步骤：**

1. 在左侧菜单点击「资产盘点」→「盘点计划」
2. 点击「新建计划」按钮
3. 填写计划信息：
   - **计划名称** *（必填）*：如「2024年Q2机房01盘点」
   - **盘点范围** *（必填）*：
     - 全部设备
     - 指定机房（选择一个或多个机房）
     - 指定机柜（选择具体机柜）
   - **计划开始时间** *（必填）*
   - **计划结束时间** *（必填）*
   - **负责人** *（必填）*：盘点总负责人
   - **参与人员**：选择参与盘点的人员
   - **备注**（选填）：盘点要求、注意事项等
4. 点击「保存」创建计划
5. 计划状态为「待执行」

#### 8.1.2 盘点任务状态

| 状态 | 说明 |
|------|------|
| **待执行** | 计划已创建，尚未开始盘点 |
| **执行中** | 盘点正在进行中 |
| **已完成** | 盘点结束，结果已提交 |

#### 8.1.3 开始盘点

到达计划开始时间后：

1. 在盘点计划列表找到目标计划
2. 点击「开始盘点」按钮
3. 系统生成盘点任务清单，状态变为「执行中」
4. 参与人员收到盘点任务通知

### 8.2 执行盘点

**盘点操作流程：**

1. 进入执行中的盘点计划
2. 系统按机柜分组展示待盘点设备清单
3. 逐个设备进行核对：
   - **确认存在**：设备在位且信息正确，点击「确认」
   - **信息有误**：如果设备信息（如位置、状态）与实际不符，点击「标记异常」并填写正确信息
   - **设备缺失**：实物不存在，点击「盘亏」并说明
   - **发现新设备**：发现清单外的设备，点击「新增到暂存」（详见8.3）
4. 支持使用扫码枪扫描设备资产编号快速定位
5. 已盘点设备显示勾选标记，可区分已盘/未盘
6. 盘点进度实时显示：已盘点数量/总数量、完成百分比

### 8.3 暂存设备管理

盘点过程中发现的账外设备先放入暂存区：

1. 在盘点页面点击「添加暂存设备」
2. 填写设备基本信息（名称、类型、序列号、所在位置等）
3. 设备存入暂存区，状态为「待核实」
4. 盘点结束后，管理员对暂存设备进行审核：
   - 信息完整且确认存在：点击「转为正式设备」，补全信息后入库
   - 信息有误：退回修改
   - 确认不存在：删除暂存记录

### 8.4 完成盘点

1. 所有设备盘点完成后，点击「提交盘点结果」
2. 系统生成盘点报告：
   - 盘点总数、盘盈数量、盘亏数量、异常数量
   - 异常设备明细
   - 暂存设备清单
3. 负责人审核报告
4. 审核通过后，点击「完成盘点」，计划状态变为「已完成」
5. 系统自动：
   - 根据盘点结果更新设备状态和信息
   - 将暂存设备转为正式设备或清理
   - 生成盘点报告存档

### 8.5 查看盘点历史

在盘点计划列表可查看历史盘点记录：
- 点击已完成的盘点计划，查看盘点报告
- 可导出盘点报告为Excel
- 对比多次盘点结果，跟踪资产变化情况

## 九、系统管理

系统管理提供用户管理、角色权限配置、系统设置等功能，仅管理员可访问。

![系统管理概览](/images/screenshots/system-management.png)

### 9.1 用户管理

#### 9.1.1 查看用户列表

1. 在左侧菜单点击「系统管理」→「用户管理」
2. 用户列表展示所有用户信息：用户名、真实姓名、角色、状态、注册时间、最后登录时间
3. 可按状态筛选（正常/待审核/已禁用）
4. 支持按用户名、姓名搜索

#### 9.1.2 审核注册用户

新用户注册后需要管理员审核：

1. 用户列表中状态为「待审核」的用户
2. 点击该用户的「审核」按钮
3. 查看用户注册信息
4. 选择：
   - **审核通过**：用户状态变为「正常」，可登录系统
   - **审核驳回**：填写驳回原因，用户收到通知后可修改重新提交
5. 提交审核结果

#### 9.1.3 编辑用户信息

管理员可编辑任意用户信息：
1. 点击用户的「编辑」按钮
2. 可修改：真实姓名、联系电话、邮箱、角色、状态
3. 点击「确定」保存

#### 9.1.4 禁用/启用用户

- **禁用用户**：点击「禁用」按钮，用户无法登录系统，正在使用的用户将被强制下线
- **启用用户**：已禁用用户点击「启用」，恢复登录权限

#### 9.1.5 重置用户密码

用户忘记密码时，管理员可重置：
1. 点击用户的「重置密码」按钮
2. 设置新密码（或生成随机密码）
3. 将新密码告知用户，建议用户登录后自行修改

#### 9.1.6 删除用户

::: warning 注意
删除用户后该用户的操作日志仍会保留，但无法恢复账号。建议优先使用「禁用」而非删除。
:::

1. 确认用户已离岗且无未完成的工作
2. 点击「删除」按钮
3. 确认删除

### 9.2 角色权限管理

系统采用RBAC（基于角色的访问控制）模型，支持灵活的权限配置。

#### 9.2.1 默认角色

| 角色 | 权限范围 |
|------|----------|
| **管理员** | 全部功能权限，包括用户管理、系统设置、所有数据的增删改查 |
| **运维人员** | 设备管理（增删改查、导入导出、端口/接线管理）、工单处理（接单、处理、完成）、耗材管理、盘点执行 |
| **普通用户** | 查看权限（查看设备、仪表盘、报表等），可创建工单、领用耗材 |

#### 9.2.2 自定义角色

管理员可创建自定义角色：

1. 进入角色管理页面
2. 点击「新增角色」
3. 填写角色名称和描述
4. 为角色分配权限：
   - **菜单权限**：勾选可访问的菜单页面
   - **操作权限**：为每个页面勾选可执行的操作（查看/新增/编辑/删除/导入/导出）
5. 点击「保存」创建角色
6. 在用户编辑页面为用户分配该角色

#### 9.2.3 分配角色

- 一个用户可拥有多个角色，权限取并集
- 管理员角色不可编辑或删除
- 修改角色权限后，对拥有该角色的所有用户立即生效

### 9.3 系统设置

进入「系统管理」→「系统设置」配置全局参数：

| 设置项 | 说明 | 操作 |
|--------|------|------|
| **站点名称** | 浏览器标签页标题和左上角显示的系统名称 | 直接输入新名称，保存后立即生效 |
| **系统Logo** | 左上角显示的Logo图片 | 点击上传，建议尺寸120×40px，PNG/SVG格式 |
| **登录页背景图** | 登录页面背景图片 | 点击上传，推荐1920×1080分辨率JPG/PNG |
| **空闲超时时间** | 无操作自动退出登录的时间 | 下拉选择：15分钟/30分钟/60分钟/永不超时 |
| **维护模式** | 开启后仅管理员可登录 | 开关切换，开启时填写维护提示信息 |
| **IP访问限制** | 限制登录IP范围 | 填写允许的IP段（如192.168.1.0/24），多个IP段用逗号分隔 |

**保存设置：**
1. 修改配置项后点击页面底部「保存」按钮
2. 站点名称、Logo、超时时间等保存后立即生效
3. 维护模式、IP限制等安全设置在下次登录时生效

## 十一、备份管理

::: tip 建议
重要数据请定期备份，防止数据丢失。
:::

### 11.1 手动备份

1. 进入「备份管理」→「备份管理」
2. 点击「立即备份」按钮
3. 系统开始创建数据库备份
4. 备份完成后，备份文件出现在备份列表中，包含：
   - 备份时间
   - 备份文件大小
   - 备份类型（手动/自动）
5. 可下载备份文件到本地保存

### 11.2 备份恢复

1. 在备份列表找到要恢复的备份文件
2. 点击「恢复」按钮
3. 仔细阅读恢复提示（恢复会覆盖当前数据）
4. 输入确认信息后点击「确认恢复」
5. 系统执行数据恢复，完成后自动刷新

::: danger 危险
数据恢复会将系统数据回退到备份时间点的状态，恢复后的数据无法找回，请谨慎操作。建议恢复前先创建当前数据的备份。
:::

### 11.3 自动备份配置

1. 进入「自动备份」标签
2. 开启「启用自动备份」开关
3. 配置备份策略：
   - **备份频率**：每天/每周/每月
   - **备份时间**：选择低峰时段（如凌晨2点）
   - **保留份数**：自动备份最多保留的份数，超出自动删除最早的备份
4. 点击「保存」配置生效

### 11.4 远端备份

支持将备份文件自动传输到远端存储：

1. 进入「远端备份」标签
2. 启用「远端备份」
3. 配置远端存储：
   - **协议类型**：FTP/SFTP/WebDAV/SMB
   - **服务器地址**：远端服务器地址
   - **端口**：服务端口
   - **用户名/密码**：认证信息
   - **存储路径**：备份文件存放路径
4. 点击「测试连接」验证配置是否正确
5. 连接测试通过后保存配置
6. 每次自动备份完成后，系统自动将备份文件同步到远端

## 附录A：常见问题FAQ

### Q1: 登录时提示「账号已锁定」怎么办？
连续3次输入错误密码会导致账号锁定15分钟，请等待15分钟后自动解锁，或联系管理员重置锁定状态。

### Q2: 设备列表加载很慢怎么办？
- 尝试使用筛选条件缩小数据范围
- 检查网络连接是否正常
- 设备数据量较大时分页加载，请耐心等待

### Q3: 导入设备失败怎么办？
- 检查模板文件格式是否正确，必填项（带*列）是否都已填写
- 查看导入结果中的失败原因，根据提示修改后重新导入
- 注意序列号不能重复，机房、机柜必须已存在

### Q4: 如何查看某台设备的所有历史工单？
进入设备详情页，切换到「工单历史」标签，即可查看与该设备相关的所有工单记录。

### Q5: 耗材库存预警如何通知？
- 耗材库存低于安全库存时，在仪表盘的「库存预警」区域显示
- （可选）配置邮件/消息通知，在系统设置中配置通知渠道

### Q6: 3D视图打不开或卡顿怎么办？
- 建议使用Chrome、Edge等现代浏览器
- 检查浏览器是否支持WebGL
- 尝试刷新页面，关闭其他占用资源的程序

### Q7: 误删了设备/工单能恢复吗？
- 目前版本删除操作不可恢复
- 建议重要数据删除前先导出备份
- 设备建议使用「已报废」状态而非删除
- 如有备份文件，可通过备份恢复但会丢失备份后的数据

### Q8: 如何修改自己的密码？
- 点击右上角用户名 → 个人设置 → 修改密码
- 输入原密码、新密码、确认新密码
- 点击保存，下次登录使用新密码
